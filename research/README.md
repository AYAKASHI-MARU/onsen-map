# 調査ルール（全国温泉マップ）

基準日: **2026年10月29日**。この日時点で営業している施設の、この日時点で有効な料金を記録する。

## 収録対象（すべて満たすもの）

1. **天然温泉**（温泉法上の温泉。源泉・運び湯を問わない）の浴槽がある。人工温泉・薬湯のみの施設は対象外。
2. **日帰り入浴**ができる（宿泊者限定は対象外）。ホテル・旅館でも、一般向けに日帰り入浴料金を常設していれば対象。
3. **サウナ**（ドライ・スチーム・ミスト・塩・遠赤外線など、浴室・浴場の設備としてのもの）を日帰り客が使える。男湯のみ・女湯のみでも可（saunaNote に書く）。水着着用の男女共用エリアにあるサウナも可（saunaNote に「水着エリア」と書く）。岩盤浴のみ・予約制の貸切（個室）サウナのみはサウナに含めない。ホテル・旅館は、日帰り客がサウナを使えると確認できたものだけ入れる。
4. 基準日時点で**営業中**。閉館・閉館予定日が基準日より前・長期休館中（改装で再開日未定など）は除外して `excluded` に理由を書く。基準日に一時休館中でも、**再開日が決まっていて基準日から2か月以内**なら収録し、`notice` に休館期間を書く。

## 料金のルール

- **大人**＝中学生以上（または12歳以上）の一般料金。会員料金・クーポン・早朝/夜間割引・回数券・セット料金（岩盤浴込みなど）は使わない。
- `weekdayAdult` ＝ 平日（月〜金・祝日以外）の昼間の通常料金。`holidayAdult` ＝ 土日祝の通常料金。同額なら同じ値を入れる。
- 税込・円の整数。**時間制**の場合は、施設が基本料金として案内している区分（多くは「2時間」「3時間」など最初の区分）を採り、ほかの区分を priceNote に書く（例: 値は 800、priceNote「3時間料金（6時間1,100円/1日1,600円）」）。1時間以下の短時間コースや「ひとっ風呂」は基本区分とみなさない。
- 短時間コースなどでサウナが使えないプランがある場合は、**サウナを使える最も基本的な一般プラン**の料金を採る（例: 「ひとっ風呂（サウナ不可）900円／1日コース 1,738円」なら 1,738円）。
- **変動料金制**（日程区分 A/B/C など）は、平日の通常区分を weekdayAdult、土日祝の通常区分を holidayAdult に入れる。対応が分からなければ平日＝最安区分、休日＝最高区分とし、priceNote に「変動料金制（1,500〜1,800円）」のように書く。
- 基準日より後の**料金改定予定**が告知されていれば、値は基準日時点の料金にし、priceNote に「2026/11/1から平日1,280円・休日1,480円」のように書く。
- 日帰り入浴が**平日のみ・土日祝のみ**の施設は、営業しない側を `null` にし、notice に「日帰り入浴は土日祝のみ」のように書く。
- 市内在住者割引など住民向けの料金がある場合は、**市外（一般）料金**を採る。曜日限定で営業している施設は収録してよい（priceNote に営業曜日を書く）。
- **銭湯**（公衆浴場の統制料金）は、基準日時点のその都道府県の大人料金を使う。サウナ料金は施設ごとに確認する。
- サウナが入浴料に含まれるなら `saunaFee: 0`。別料金なら金額（例: 300）。不明なら `null`。
- 深夜割増・入湯税の別途徴収などは `priceNote` に短く書く（例: 「入湯税150円別」「深夜1時以降 +1,500円」）。
- 料金が確認できない施設は、原則として収録しない。どうしても収録する価値がある場合のみ `null` にして `confidence: "low"`。

## 情報源の優先順位

1. 施設の**公式サイト**（料金ページ・お知らせ）。料金改定のお知らせがあれば、基準日に有効な料金を採る。
2. 自治体・観光協会の公式ページ。
3. ニフティ温泉・サウナイキタイ・じゃらん等のポータル（公式で確認できないときの補助。最終更新日が新しいものを優先）。

公式サイトで確認できたものは `confidence: "high"`、ポータルのみ（更新日が新しい）は `"medium"`、情報が古い・食い違いがあるものは `"low"`。

**推測で値を埋めない。** 座標（緯度経度）は書かない（住所から機械的にジオコーディングする）。

## 出力形式

`research/raw/<都道府県コード2桁>-<ローマ字>[-<地域>].json` に UTF-8 の JSON で保存する。

```json
{
  "prefecture": "神奈川県",
  "prefCode": "14",
  "area": "",
  "researchedAt": "2026-10-29",
  "facilities": [
    {
      "name": "施設の正式名称",
      "address": "神奈川県足柄下郡箱根町湯本○○番地",
      "weekdayAdult": 1200,
      "holidayAdult": 1500,
      "saunaFee": 0,
      "priceNote": "",
      "saunaTypes": ["ドライ", "スチーム"],
      "saunaNote": "",
      "url": "https://公式サイト",
      "sources": ["https://料金を確認したページ"],
      "confidence": "high",
      "notice": "",
      "note": ""
    }
  ],
  "excluded": [
    { "name": "○○温泉", "reason": "2025年3月閉館" }
  ],
  "notes": "調査の範囲・取りこぼしがありそうな地域など"
}
```

- `address` は都道府県名から始まる正式な住所（番地まで）。
- `saunaTypes` は ["ドライ", "スチーム", "ミスト", "塩", "遠赤外線", "ロウリュ可", "その他"] から選ぶ。
- `notice` は**アプリにそのまま表示する利用者向けのお知らせ**（定休日・臨時休館・短期休館・曜日限定営業など）。
- `note` は調査メモ（情報源の事情など。アプリには表示しない）。
- 文字列は短く。`notice` と `note` は書くことがあるときだけ。
